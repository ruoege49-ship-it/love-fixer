# 功能介绍

所有功能都从**顶栏的路线图标**进。三条杠菜单里也有两个入口：「Love 修正机」和「讲解：点哪讲哪」。

点开总入口，从上到下是：

| 位置 | 是什么 | 什么时候用 |
|---|---|---|
| 最上面 | **新手引导** | 第一次用，先做这个 |
| 两个大按钮 | **帮我查问题** / **优化设置** | 出问题了 / 想调设置 |
| 看不懂？ | 讲解、问小助手、词典、带我学 | 界面上哪儿不认识 |
| 平时聊天 | 快捷台、做大总结 | 日常顺手用 |

刚报过错时，「帮我查问题」会标上“刚才有报错”；聊天超过 10 万 token 时，「做大总结」会标上“该做了”。

---

## 1. 新手引导

一张九步的清单，修正机自己判断哪步做完了，做完的打勾：

1. 切成中文
2. 连上 API
3. 配好小助手（可选）
4. 导入预设
5. 导入角色卡
6. 装酒馆助手（可选）
7. 认识正则（可选）
8. 写 user 设定
9. 发出第一句话

点「下一步」就带你去做下一项没做的。每一步都会打开对应的面板，**用红框框出要点的地方**，底下的「小助手 · 带你做」窗口说明怎么操作。要框的东西被窗口挡住时，会自动滚上来，或者把窗口挪到屏幕顶上。

配 API 时会帮你填好接口类型和来源；用中转的话，**提示词后处理**会帮你选不带工具的「严格」。密钥要你自己填；配置向导只判断酒馆密钥框是否已填，不保存这处的密钥。

---

## 2. 帮我查问题

出问题了就点这个，按顺序走：

**① 自动体检**：一打开就查一遍常见问题。能修的点一下就修好，比如：

- 接口不是聊天补全
- 回复长度太小、上下文太小
- 局部正则、预设正则的「允许」开关关着
- 卡要用的酒馆助手、提示词模板没装
- 聊天超过 10 万 token 没做大总结
- 没写 user 设定
- 用中转时提示词后处理不是「严格」
- 哈基米开着真流、回复被截断
- 用 Gemini 3.1 Pro、3.6 Flash 起的模型，预设里还开着预填
- 开着内容一字不差的重复条目

**② 让小助手看屏幕**：还没解决，就让小助手读一遍屏幕状态和报错（不读密钥），直接告诉你怎么办。要先接 API。

**③ 去答疑提问**：前面都没解决，再去社区的「新手答疑」问人。修正机会帮你：

- 把版本、设备、渠道和模型、中转地址、预设、卡、报错原文**自动填进提问草稿**
- 接了 API 的话，小助手会追问几句，把「我做了什么 → 想要什么 → 实际怎样 → 试过什么」问清楚，写成完整的提问
- 列出该截哪几张图，点「带我去」直接框出来

> 截图只遮**密钥**、真名和联系方式。**中转地址不要遮**，答疑的人要靠它判断地址填得对不对。

最下面是「修过的设置」：修正机替你改过的每一项都记着，可以一条条还原，也可以全部还原。

另外有一张「条目之间有没有打架？」：体检只报能确定的问题，人称、字数、文风这类要读懂意思的，点它让小助手把开着的预设条目读一遍。

## 3. 优化设置

最上面是**快速优化**，会认出你用的是手机还是电脑，推荐一个方案：

| 方案 | 干什么 |
|---|---|
| 推荐 | 大多数人用这个：报错自动解释、收起少用的消息按钮、草稿防丢、回到底部、导入提醒、大总结提醒 |
| 手机 | 推荐的全部，再加：关掉模糊和动画、只加载最近楼层、回车换行不发送、关滑动切回复、面板全屏、按钮放大 |
| 极简 | 推荐的全部，再加：打开直接进上次的聊天、关掉模糊和动画、点选隐藏不用的按钮 |
| 全关 | 修正全部关掉，酒馆恢复原样 |

点一下就换，换完会提示这次打开、关掉了哪几项。

下面还有：

- **修正机外观**：日间 / 夜间 / 跟随酒馆，夜间有「黑与白」「黑蓝深海」两套，和智库一样。
- **新手模式**：收起高级格式化、背景和用不上的扩展；预设、世界书、user 设定、美化、酒馆助手、正则、提示词模板都留着。
- 各组开关：界面精简、后台优化、聊天、手机端、生成、功能开关、小助手设置。

## 4. 看不懂？

- **讲解**：开了以后，点酒馆里任意地方，红框框住它并告诉你这是干嘛的。预设条目会讲它排在第几、深度 D 几、起什么作用；设置项会讲人话版，比如温度、提示词后处理、流式。点「问问它」可以接着问。
- **问小助手**：直接打字问。可以借用酒馆当前的连接，也可以单独填一个便宜的模型。
- **词典**：分「黑话」和「介绍」两类。黑话是圈里的说法，比如破限、八股、PVP、爆代码；介绍是功能说明，比如真流 / 假流 / 非流、提示词后处理、更新卡、XML 标签、别滥用 Markdown。
- **带我学**：边框边教的小课，包括：
  - 基础操作：写 user 设定、怎么发第一句话、抽卡改楼删楼、小铅笔、继续和重新生成
  - 预设和正则：预设条目开关、看 AI 收到了什么、正则面板、思考怎么折叠
  - 世界书和卡：做一本世界书、编辑角色卡、怎么做大总结、怎么更新角色卡、AI 失忆怎么办
  - 维护和设置：备份和换设备、更新酒馆和扩展、连接配置文件、快速回复、怎么换美化
  - 图文教程：怎么去答疑提问、怎么安装扩展、怎么切成中文

## 5. 平时聊天

- **快捷台**：选卡（搜索、标签、收藏、最近聊过）、切换和改名聊天、跳到第几楼、换 char 头像（只改这个聊天，也能写入卡）、换 user 头像、换字体和字号，还有时间记录（这次在线、今天在线、平均每条等多久）。
- **做大总结**：八步带你做完：
  1. 看现在有多少 token
  2. 打开预设里的大总结条目
  3. 填总结指令（会要求保留状态栏数值）
  4. 检查总结
  5. 一键存进这个聊天专用的世界书，自动设成蓝灯、角色定义之后
  6. 删掉“要求总结”和“总结”这两楼
  7. 隐藏旧楼，留最近 10 楼
  8. 关掉大总结条目

## 6. 自己会弹出来的提醒

提醒会排队，一次只弹一个；AI 正在写、向导或弹窗开着的时候先等着。

- **报错自动解释**：酒馆弹红色报错时，告诉你是什么意思、怎么办，比如 429 撞车、524 超时、400 预设不匹配、预填不适配。
- **爆代码**：聊天里露出代码时，告诉你缺哪个扩展。都装了还爆，常见于切换开场白，会提示去提示词模板「先重置，再取消勾选先处理原始内容」。
- **导入提醒**：卡里带脚本、带正则，或者缺扩展时提醒一句；导入全局正则时，提醒它会在所有卡里生效；导入同名卡时，提醒先把原本的世界书重命名或删掉。
- **大总结提醒**：发给 AI 的聊天记录超过 10 万 token 提醒一次，每多 10 万再提醒。
- **玩久了提醒休息**：默认关着，在优化设置里打开。

## 隐私

- 配置向导只判断酒馆密钥框是否已填，不保存这处的密钥。
- 开启「输入框草稿防丢」后，未发送的文字会保存在本机浏览器。
- 小助手「看屏幕」读的是界面状态文字，不是截图，所以 DeepSeek 这种不能看图的模型也能用。
- 小助手单独填写的密钥保存在本机浏览器，并用于请求你选定的接口。
- 时间记录只存在这台设备上。
